3. For each of the following pairs of scanf format strings, indicate whether or not the two
strings are equivalent. If they're not, show how they can be distinguished.

(a) "%d"        versus  " %d"
(b) "%d-%d-%d"  versus  "%d -%d -%d"
(c) "%f"        versus  "%f "
(d) "%f,%f"     versus  "%f, %f"

Answer:
(a) Yes. The whitespace is skipped.
(b) No. Initial string expects (-) as input right after the digit and would fail with a whitespace.
(c) No. The second string keeps reading input until a non-whitespace character is entered"
(d) Yes. The whitespace is skipped.
